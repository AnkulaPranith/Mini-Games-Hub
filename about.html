About Mini Games Hub

A simple and fun platform where entertainment meets creativity, logic, and learning.

Our Project

Mini Games Hub is a web-based gaming application developed using HTML, CSS, JavaScript, and Bootstrap 5. It provides different mini games in one place.

Players can enjoy number guessing, rock paper scissors, memory cards, and tic tac toe. The project demonstrates frontend development concepts and JavaScript programming.

2 CSS3 Styling and page design
3 JavaScript Game logic and interactivity
4 Bootstrap 5 Responsive layouts and components
